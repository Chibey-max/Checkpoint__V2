## What failed on the way, and the fixes

- **The public RPC (`rpc.testnet.near.org`) dropped calls.** Guard failed closed with `GUARD_UNAVAILABLE` (AT-14 behaving as designed), so no basket got signed. Fixes: `.env` now uses **FastNEAR** (`https://rpc.testnet.fastnear.com`, about 0.9 s against 3.9 s), and shared `viewFunction` retries a network failure once before failing. **Proposal for D-04: FastNEAR.**
- **The agent account ran out of NEAR.** Each `execute_basket` reserves 300 TGas up front, and `agent.cpdemo.testnet` had 0.19 NEAR. It was topped up to 2.49 NEAR from a faucet-funded account. The function-call key's allowance is fine: 0.99 of 1 NEAR left.
- **The settlement module now keeps the transaction hash of a rejected call,** so attack evidence can link to nearblocks.
